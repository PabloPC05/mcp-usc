# mcp-usc 0.9.0 — experiencia MCP y compatibilidad

La v0.9 conserva las 84 herramientas de v0.8 y añade una capa de descubrimiento y flujos guiados sin
ampliar permisos ni ejecutar operaciones por sí misma.

## Novedades

- cuatro recursos locales: `usc://about`, `usc://safety`, `usc://compatibility` y
  `usc://workflows`;
- cuatro prompts elegidos por el usuario: resumen académico, planificación de exámenes, revisión de
  tareas y preparación segura de una entrega;
- `mcp-usc manifest`, con esquemas completos, recuentos y SHA-256 determinista;
- `mcp-usc doctor --compact` para copiar un diagnóstico sanitizado en una sola línea;
- CI en Linux, Windows y macOS con Python 3.11 y 3.13;
- workflow de release que valida el tag, prueba, construye, instala el wheel limpio, genera
  `SHA256SUMS` y publica los artefactos;
- documentación específica de superficie MCP, compatibilidad y releases.

## Compatibilidad

No cambian nombres ni parámetros de las 84 herramientas de v0.8. Los hosts sin interfaz para
recursos o prompts pueden seguir usando todas las herramientas. El mínimo del SDK pasa a
`mcp>=1.29,<2` para fijar el contrato probado.

## Seguridad

Los recursos y prompts son funciones locales sin red. Ningún prompt ejecuta una herramienta por sí
mismo. `prepare_assignment_submission` exige detenerse después del preview y mantiene la
confirmación humana para un turno posterior. El manifiesto no carga configuración, keyring o datos
del Campus y no incluye contenido de los recursos.

No se enviaron mensajes ni se realizaron operaciones sobre el Campus durante el desarrollo.
