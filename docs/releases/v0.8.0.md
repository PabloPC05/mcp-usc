# mcp-usc 0.8.0 — beta comunitaria

La versión 0.8 convierte el repositorio en un proyecto que una persona nueva puede descubrir,
instalar, evaluar y contribuir sin conocer su historia previa.

La evidencia completa de validación está en la
[revisión de release](../release-review-v0.8.0.md).

## Para usuarios

- El README explica primero qué problema resuelve, para quién es y qué peticiones admite.
- `mcp-usc doctor` distingue una instalación lista para datos privados de una instalación
  `public_only`, sin usar la red ni imprimir credenciales.
- `describe_mcp_usc` permite que el propio asistente explique el alcance, los límites y las 84
  herramientas disponibles.
- La nueva guía separa instalación, autenticación, conexión MCP, subidas y diagnóstico.

## Para contribuidores

- CI ejecuta lint, 450 tests y build con `uv.lock` congelado.
- El inventario autodescriptivo se compara con el servidor STDIO real en tests.
- Se añaden arquitectura, roadmap, changelog, seguridad, contribución, conducta, soporte y plantillas
  estructuradas de GitHub.
- Los metadatos del paquete incluyen URLs, palabras clave y clasificadores.

## Compatibilidad

No hay cambios incompatibles en nombres ni parámetros de las 83 herramientas de v0.7. La única
herramienta MCP nueva es `describe_mcp_usc`. `doctor` es un nuevo subcomando local.

## Seguridad y privacidad

No se enviaron mensajes, foros, entregas ni otras operaciones al Campus durante el desarrollo de
esta versión. Las pruebas usan dobles locales. El diagnóstico lee como máximo la presencia de
`moodle-session` en keyring y nunca devuelve su contenido.
